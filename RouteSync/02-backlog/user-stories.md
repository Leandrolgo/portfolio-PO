
# Histórias de Usuário (User Stories) — RouteSync

Aqui estão documentadas as regras de negócio e necessidades dos nossos usuários para o desenvolvimento do ecossistema RouteSync.

---

### US01 — Visualização de Rota pelo Motorista
**Como um** Motorista de Entrega  
**Eu quero** visualizar minha rota diária otimizada num aplicativo móvel  
**Para que** eu possa realizar as entregas sem atrasos e evitar caminhos congestionados.

### US02 — Painel de Monitoramento do Supervisor
**Como um** Supervisor de Logística  
**Eu quero** acompanhar o status das rotas dos motoristas em tempo real num dashboard web  
**Para que** eu possa intervir rapidamente em caso de imprevistos ou desvios de rota.
