# Jornada do Usuário (User Journey) — RouteSync

Esta jornada mapeia o fluxo básico diário de ponta a ponta, demonstrando como o aplicativo e o dashboard resolvem as dores dos usuários em tempo real.

| Etapa | Ação do Usuário | O que o RouteSync faz por trás (Valor do Produto) |
| :--- | :--- | :--- |
| **1. Planejamento** | **Roberto (Supervisor)** entra no Dashboard Web no início da manhã. | O sistema consolida as entregas e gera automaticamente as rotas otimizadas para o dia. |
| **2. Início da Rota** | **Cadu (Motorista)** abre o aplicativo no celular antes de sair do pátio. | O app já exibe a rota calculada, a ordem de paradas e o tempo estimado de chegada. |
| **3. Imprevisto** | **Cadu** encontra um bloqueio de pista inesperado devido a obras na avenida. | O aplicativo detecta a retenção de velocidade, recalcula a rota na hora e notifica o painel do escritório. |
| **4. Monitoramento** | **Roberto** visualiza um alerta de atraso no Dashboard. | Em vez de ligar para o motorista, Roberto vê no mapa do painel que o Cadu já está contornando o bloqueio por uma rota alternativa. |
| **5. Conclusão** | **Cadu** finaliza a última entrega e clica em encerrar. | O sistema registra o horário final e gera métricas de performance para o relatório mensal do Roberto. |
